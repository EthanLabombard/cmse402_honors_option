# CMSE 402 Honors Option - Plotly Choropleth Map Tutorial

### Contained within this repository is two files, the choropleth_map.ipynb, which contains the tutorial itself, and the CMSE 402 Honors Writeup, which contains the written explanation behind this tutorial. 

#### The objective behind this tutorial is to give a demonstration of some of the different features of the choropleth mapping function and present examples of how these may look. To use the tutorial, open the choropleth_map.ipynb file and examine the different examples presented in the code. Within the code the fig.show() lines in the examples are commented out to keep the file size down, these can be uncommented to see what the figures would look like for each example.
